# Template — Script découpé en scènes (pour Pictory / InVideo AI / Fliki)

Comment utiliser ce format :
1. Copier uniquement le texte après "**Texte** :" de chaque scène, dans l'ordre, dans le champ script de l'application.
2. La ligne "**Visuel suggéré**" n'est pas à coller dans le script — c'est une indication pour toi, à taper manuellement dans le champ "mot-clé visuel" de la scène si l'outil le permet (Pictory et InVideo AI proposent souvent un mot-clé par scène après la génération automatique).
3. Une scène = un paragraphe = un changement de plan. Ne pas fusionner plusieurs scènes en un seul bloc de texte, sinon l'outil ne changera pas de visuel au bon moment.

## Format d'une scène

**Scène X**
**Visuel suggéré** : (2-4 mots-clés simples et concrets, en français ou anglais selon l'outil)
**Texte** : (le texte exact à coller dans l'application)

## Note sur la durée réelle

Un script d'environ 450-550 mots donne 3 à 4 minutes de vidéo en voix off à
un rythme normal (140-150 mots/minute). Pour un 10-15 minutes réel, il
faut environ 1500-2200 mots — soit sensiblement plus de scènes que ce que
les scripts actuels contiennent. Les fichiers `jour-XX-scenes.md` reflètent
la longueur réelle des scripts existants (~3-4 min), pas encore un format
10-15 min.
