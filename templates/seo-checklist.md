# Checklist SEO YouTube — à appliquer sur chaque vidéo

## Titre
- [ ] 60 caractères max (ne pas être coupé dans les résultats)
- [ ] Contient soit un bénéfice clair, soit une tension/curiosité
- [ ] Mot-clé principal dans les 3 premiers mots si possible
- [ ] Pas de clickbait mensonger (fait chuter la rétention et la confiance)

## Description
- [ ] Première phrase = accroche + mot-clé principal (visible avant "voir plus")
- [ ] Résumé en 2-3 phrases de ce qu'on apprend dans la vidéo
- [ ] Timestamps si la vidéo a plusieurs parties
- [ ] Lien(s) d'affiliation pertinents (livres/outils cités)
- [ ] CTA vers l'abonnement ou une autre vidéo liée
- [ ] 3-5 hashtags maximum en fin de description

## Tags
- 3-5 tags larges (ex: développement personnel, motivation, mindset)
- 5-8 tags niche/spécifiques au sujet exact de la vidéo
- 2-3 tags avec le nom de la chaîne / variantes de marque

## Miniature
- [ ] Contraste fort (se détache dans un flux de recommandations)
- [ ] Texte court (3-5 mots max), lisible en miniature (mobile)
- [ ] Émotion ou visage si pertinent (le regard capte l'attention)
- [ ] Cohérente avec le titre, pas de mensonge visuel

## Avant publication
- [ ] Vérifier que le hook des 15 premières secondes tient sa promesse
- [ ] Sous-titres/captions ajoutés
- [ ] Playlist appropriée assignée
- [ ] Card/end screen vers la vidéo suivante ou l'abonnement
