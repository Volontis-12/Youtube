# Template — Script Short (30-60 sec)

Deux types de shorts par jour :

## Type A — Extrait du long format
Reprendre le passage le plus fort du script long (statistique choc,
histoire, punchline) et le recadrer pour tenir seul en 30-45 sec :
1. Hook identique ou renforcé dans les 2 premières secondes
2. Le passage fort tel quel (ou légèrement raccourci)
3. Une phrase de chute qui donne envie d'aller voir la vidéo longue
4. Texte à l'écran : "Vidéo complète en lien / sur la chaîne"

## Type B — Short autonome
Format qui n'a pas besoin du long format pour fonctionner :
- **Hook (0-2 sec)** : phrase choc ou question
- **Corps (5-30 sec)** : un conseil unique, une citation commentée en 2
  phrases, ou un format liste ("3 signes que...", "2 choses que les gens
  qui réussissent font tous les matins")
- **Chute (dernières 3-5 sec)** : phrase mémorable ou question pour les
  commentaires

## Règles pour tous les shorts
- Jamais d'intro/outro — on coupe dans le vif du sujet dès la 1ère seconde
- Sous-titres obligatoires (la majorité regarde sans son)
- 1 idée par short, jamais plus
- Texte à l'écran pour le hook, même si la voix off le dit aussi
